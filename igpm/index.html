IGP-M

As taxas mensais são retornadas como Decimal em yd.igpm.taxa() e como Decimal(18, 4) na coluna taxa de yd.igpm.taxa_serie(). A unidade é decimal: Decimal("0.0027") representa 0,27%. Os valores são convertidos diretamente do texto do SGS/BCB, sem passagem por float.

Quando indisponível, a consulta escalar retorna Decimal("NaN"); use .is_nan() para verificar. A consulta de série retorna um DataFrame vazio com o mesmo esquema. A série de taxas representa a variação mensal.

Os números-índice são obtidos com yd.igpm.indice(data) e yd.igpm.indice_serie(inicio, fim) ou yd.igpm.indice_serie(ultimos=n). A fonte é a FGV/Conjuntura Econômica, disponibilizada pelo Ipeadata na série IGP12_IGPM12. O retorno escalar usa Decimal e a coluna indice usa Decimal(18, 10): as dez casas preservam os valores antigos, anteriores a 1994. A coluna periodo identifica a competência no formato YYYYMM. O índice indisponível retorna Decimal("NaN") na consulta escalar.

Nas séries de índices, qualquer dia identifica o mês inteiro; os dois meses extremos são incluídos. fim=None usa a data atual no Brasil. Informe inicio ou ultimos; quando informado, ultimos tem prioridade sobre as datas.

Calendário de divulgação

yd.igpm.calendario(ano, atualizar=False) consulta as divulgações mensais na FGV IBRE, excluindo as prévias decendiais e os demais índices. Retorna competencia e data_divulgacao, ambas Date. A competência corresponde ao mês da divulgação mensal. Datas ausentes não são estimadas, e o calendário não comprova publicação. atualizar=True renova o cache de 60 segundos do ano.

calendario = yd.igpm.calendario(2026)

def calendario(ano: int, *, atualizar: bool = False) -> pl.DataFrame:
    """Consulta o calendário de divulgação mensal do IGP-M na FGV IBRE.

    Args:
        ano: Ano das divulgações e competências.
        atualizar: Ignora e renova o cache de 60 segundos desse ano.

    Returns:
        DataFrame ordenado por competência. Sem registros, retorna vazio com
        o mesmo esquema.

    Output Columns:
        competencia (Date): Primeiro dia do mês da divulgação mensal do IGP-M.
        data_divulgacao (Date): Data prevista pela FGV IBRE.

    Notes:
        Fonte: calendário de divulgação da FGV IBRE. Seleciona o IGP-M mensal
        com seus componentes, excluindo prévias decendiais e outros índices.
        A competência corresponde ao mês da divulgação mensal. A data prevista
        não comprova publicação. Não cria janelas estimadas quando faltam dados.
        Erros de rede e payload inválido são propagados.

    Raises:
        ValueError: Ano inválido, data inválida ou datas conflitantes.
    """
    if type(ano) is not int or not dt.MINYEAR <= ano <= dt.MAXYEAR:
        raise ValueError("ano deve ser um inteiro entre 1 e 9999.")
    return _processar_calendario(
        _parsear_calendario(_buscar_calendario(ano, _atualizar=atualizar))
    ).filter(pl.col("competencia").dt.year() == ano)

def indice(data: DateLike | None) -> Decimal:
    """Obtém o número-índice do IGP-M para um mês específico.

    Fonte: FGV/Conjuntura Econômica, disponibilizada pelo Ipeadata na série
    ``IGP12_IGPM12``, com base agosto de 1994 = 100.

    Args:
        data: Qualquer data dentro do mês desejado, nos formatos da biblioteca.

    Returns:
        Decimal: Número-índice com dez casas decimais ou ``Decimal('NaN')``
        se a data for nula, vazia ou o índice não estiver disponível.

    Examples:
        >>> yd.igpm.indice("01-06-2000")
        Decimal('183.7450000000')
        >>> yd.igpm.indice("01-06-1989")
        Decimal('0.0000308619')
    """
    if data is None or any_is_empty(data):
        return Decimal("NaN")
    df = indice_serie(data, data)
    if df.is_empty():
        return Decimal("NaN")
    return df.item(0, "indice")

def indice_serie(
    inicio: DateLike | None = None,
    fim: DateLike | None = None,
    *,
    ultimos: int | None = None,
) -> pl.DataFrame:
    """Obtém os números-índice mensais do IGP-M por intervalo ou últimos meses.

    Fonte: FGV/Conjuntura Econômica, disponibilizada pelo Ipeadata na série
    ``IGP12_IGPM12``, com base agosto de 1994 = 100.

    Args:
        inicio: Qualquer data no primeiro mês do intervalo.
        fim: Qualquer data no último mês do intervalo. Se ``None``, usa a
            data atual no Brasil.
        ultimos: Número de meses mais recentes a recuperar. Se informado,
            tem prioridade sobre ``inicio`` e ``fim``.

    Returns:
        DataFrame com os números-índice em ordem crescente de competência.
        Retorna vazio, preservando o esquema, se não houver dados no intervalo.

    Output Columns:
        * periodo (Int64): competência mensal no formato YYYYMM.
        * indice (Decimal(18, 10)): número-índice do IGP-M.

    Notes:
        Os números do JSON são lidos diretamente como Decimal, sem passagem
        por float. As dez casas preservam também os valores anteriores a 1994,
        que podem ser menores que 0.001. Valores ausentes são omitidos.

    Raises:
        ValueError: Se não informar ``inicio`` nem ``ultimos``, se ``ultimos``
            for menor ou igual a zero ou se alguma data for inválida.

    Examples:
        >>> yd.igpm.indice_serie("01-06-2000", "31-07-2000").to_dicts()
        [{'periodo': 200006, 'indice': Decimal('183.7450000000')},
         {'periodo': 200007, 'indice': Decimal('186.6340000000')}]
    """
    if ultimos is not None:
        if ultimos <= 0:
            raise ValueError("O número de meses deve ser maior que 0.")
        return _processar_historico(_parsear_historico(_buscar_historico())).tail(
            ultimos
        )
    if inicio is None:
        raise ValueError("Informe 'inicio' ou 'ultimos'.")
    data_inicio = converter_datas(inicio)
    data_fim = converter_datas(fim) if fim is not None else relogio.hoje()
    if data_inicio is None or data_fim is None:
        raise ValueError("As datas do intervalo devem ser informadas.")
    periodo_inicio = data_inicio.year * 100 + data_inicio.month
    periodo_fim = data_fim.year * 100 + data_fim.month
    if periodo_inicio > periodo_fim:
        return pl.DataFrame(schema=_ESQUEMA)
    return _processar_historico(_parsear_historico(_buscar_historico())).filter(
        pl.col("periodo").is_between(periodo_inicio, periodo_fim)
    )

def igpm_taxa_serie(
    inicio: DateLike | None = None,
    fim: DateLike | None = None,
    *,
    ultimos: int | None = None,
) -> pl.DataFrame:
    """Obtém as taxas mensais do IGP-M via SGS do Banco Central (série 189).

    O índice é produzido pela FGV. A série representa a variação mensal,
    não o número-índice nem a variação acumulada em 12 meses.

    Args:
        inicio: Qualquer data no primeiro mês do intervalo.
        fim: Qualquer data no último mês do intervalo. Se ``None``, usa a
            data atual no Brasil.
        ultimos: Número de meses mais recentes a recuperar. Se informado,
            tem prioridade sobre ``inicio`` e ``fim``.

    Returns:
        DataFrame com as taxas mensais em decimal, ou vazio se não houver dados.

    Output Columns:
        * periodo (Int64): competência mensal no formato YYYYMM.
        * taxa (Decimal(18, 4)): variação mensal em decimal (0.005 = 0,50%).

    Notes:
        Os valores percentuais são convertidos diretamente do texto do SGS
        para Decimal e divididos por 100, sem passagem por float.

    Raises:
        ValueError: Se não informar ``inicio`` nem ``ultimos``, ou se
            ``ultimos`` for menor ou igual a 0.

    Examples:
        >>> df = yd.igpm.taxa_serie("01-01-2025", "31-03-2025")
        >>> df = yd.igpm.taxa_serie(ultimos=12)
    """
    if ultimos is not None:
        if ultimos <= 0:
            raise ValueError("O número de meses deve ser maior que 0.")
    else:
        if inicio is None:
            raise ValueError("Informe 'inicio' ou 'ultimos'.")
        inicio = converter_datas(inicio).replace(day=1)
        fim = converter_datas(fim).replace(day=1) if fim is not None else None
    return (
        _buscar_serie(SerieSGS.IGPM, inicio, fim, ultimos)
        .select(
            periodo=pl.col("data").dt.strftime("%Y%m").cast(pl.Int64),
            # A divisão decimal do Polars preserva a escala do numerador.
            taxa=(pl.col("valor").cast(pl.Decimal(precision=18, scale=4)) / 100).cast(
                pl.Decimal(precision=18, scale=4)
            ),
        )
        .sort("periodo")
    )
